# Analyst symbol map for the multiplayer image (default_mp.xex, TU6).
#
# The recompiled C++ in ppc_mp/ is generated and keyed by address, so it only
# knows functions as sub_<ADDR>. This sidecar gives them readable names for the
# analysis tools (tools/xref.py and tools/callgraph.py, through tools/title.py's
# symbol lookup). It changes nothing in the build; edit freely.
#
# Format: one entry per line, `ADDR  name` (ADDR hex, 0x optional). Blank lines
# and # comments are ignored. Names are analyst-assigned (not official IW
# symbols); where identity is uncertain it is noted inline.
#
# Provenance: a review of the multiplayer's network code against the known
# IW4 vulnerabilities (docs/security.md lists the fixes). Most were pinned by decoding string-compare immediates, data-global xrefs, and
# the call graph.
#
# The last section is imported from codxe's TU6 multiplayer table.
